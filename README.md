✅ *Programming Basics – Part 2*   

*Data Types, Boolean Logic & Operators.*  

➊ *Data Types* – Different kinds of values you can store.  
📌 Common Types:  
✔ `int` – Whole numbers (e.g., 5)  
✔ `float` / `double` – Decimal numbers (e.g., 3.14)  
✔ `char` – Single character (e.g., 'A')  
✔ `string` – Text (e.g., "Hello")  
✔ `bool` / `boolean` – True or False  

📍 Python:  
```python  
age = 25        # int  
pi = 3.14       # float  
name = "Alex"   # string  
is_valid = True # bool  
```  
📍 Java  
```java  
int age = 25;  
double pi = 3.14;  
String name = "Alex";  
boolean isValid = true;  
```

➋ *Boolean Logic* – Helps your code make decisions.  
✔ `True` / `False`  
✔ Logical operators:  
• `and` / `&&` – Both must be true  
• `or` / `||` – At least one is true  
• `not` / `!` – Opposite of a condition  

📍 Python:  
```python  
if is_valid and age > 18:  
    print("Access granted")  
```  
📍 Java
```java  
if (isValid && age > 18) {  
    System.out.println("Access granted");  
}
```

➌ *Operators* – Used for comparisons & calculations.  

✔ *Arithmetic:*
`+` (add), `-` (subtract), `*` (multiply), `/` (divide), `%` (modulo)  

✔ *Comparison:*  
`==` (equal), `!=` (not equal), `>` , `<`, `>=`, `<=`  

✔ *Assignment:*  
`=`, `+=`, `-=`, `*=`, `/=`

📍 Example:  
```python  
x = 5  
x += 2  # Now x is 7  
```
